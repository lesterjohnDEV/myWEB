1. Project Description

This project is a personal portfolio landing page developed for CCC181 Laboratory 1. It introduces me as a BSIT student, highlights my IT skills and interests, showcases sample academic projects, and provides ways to contact me.

The webpage is built using HTML and CSS, with JavaScript for interactive features when needed. Bonezegei Scripting Language (BSL) and the provided HTTP server framework are used to run the portfolio locally.

Open the integrated terminal and make sure it is set to the project directory.

5. How to Run the Application

Open the VS Code terminal and install the required dependencies:

bzg install

After installation, start the application:

bzg run

Once the server starts successfully, open a web browser and visit:

http://localhost:8000

Keep the terminal open while using the website. If the commands or port differ in the provided starter project, follow the project's actual configuration.
